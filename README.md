# Todo CLI

Консольное приложение для управления задачами на Python.

## Возможности

- добавление задач;
- просмотр списка задач;
- отметка задачи как выполненной;
- удаление задач;
- сохранение задач в JSON-файл.

## Технологии

- Python
- JSON
- Git
- GitHub

## Запуск

Клонировать репозиторий:

```bash
git clone https://github.com/ibragim940/todo_cli.git
```

Перейти в папку проекта:

```bash
cd todo_cli
```

Запустить приложение:

```bash
python main.py
```

## Цель проекта

Проект создан для практики Python, работы с файлами JSON, функциями, структурами данных и Git.
